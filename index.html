01AI agent · Live

Buyer Finder

An AI agent that finds real overseas buyers for small exporters.

Tell it what you sell and which country you want to sell to. It finds real local importers and distributors, shows the evidence for each company, and drafts the first outreach email.

Small exporters still find new clients through referrals, trade fairs and hours of manual searching, and the data online is often wrong. Checking companies one by one costs too much time.

How it works

  1. Search. Chinese input is translated to English first, then it searches for local companies.
  2. Filter. Drops platforms, directories and manufacturers. Only companies that appear in real search results are kept, so the AI can't invent them.
  3. Check evidence. The AI must quote its source word for word; code then opens the page and checks the quote.
  4. Confirm the website by domain, language and phone area code.
  5. Score. The AI answers 4 yes/no questions and code computes the score, so the same answers always get the same score.
  6. Draft the email. Drafts only, never sends.

Python · Streamlit · DeepSeek / Claude API · web search API · English and Chinese UI
